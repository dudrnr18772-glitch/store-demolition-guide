## GitHub 업로드 — 매우 중요

**이 ZIP은 기존 GitHub 저장소에 덮어쓰는 '변경 파일 묶음(overlay)'입니다. 단독 새 프로젝트가아닙니다.**

1. GitHub 저장소의 `master` 브랜치가 현재 운영 배포 브랜치인지 확인합니다.
2. 기존 저장소를 백업합니다(Download ZIP 또는 별도 브랜치).
3. 이 ZIP을 PC에서 압축 해제합니다.
4. 안의 `app`, `components`, `lib`, `data`, `public`, `scripts`, `docs` 폴더와 `package.json`, `netlify.toml`을 기존 **저장소 루트 경로**로 업로드·덮어씁니다. 파일들이 `원상복구업체_GitHub_업로드용_수정파일/` 아래의 하위 폴더로 들어가지 않게 주의하세요.
5. **기존에 있던 `data/pages.csv`, `lib/detail-content.ts`, `scripts/check-pages.ts`, `package-lock.json`, 기타 기존 파일을 삭제하지 마세요.** 현재 운영 URL 7,155개를 유지하는 데 필요합니다.
6. Commit changes 후 Netlify 자동 빌드 결과를 확인합니다.
7. 메인, 9개 우선개선 페이지, 11개 새 페이지, 모바일 메뉴, 상담 링크, 실제 시공 이미지, 사이트맵을 확인합니다.

GitHub 웹 화면은 ZIP을 자동으로 풀어 적용하지 않습니다. **압축 해제 후 파일·폴더를 업로드**해야 합니다. 브랜치를 잘못 업로드하면 운영 반영이 안 될 수 있습니다.
